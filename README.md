# Seraya Airways

A fictional airline booking and management platform built with Next.js.

## Getting started

1. Install Node.js 20.9 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Current status

- Premium Seraya Airways landing page
- Interactive one-way / return flight search form
- Responsive navigation and destination cards
- Booking, account and administration sections are planned

## Important

This is a roleplay project. Payments will be simulated only. Do not enter real card details, banking passwords or OTPs.
